§1

任務摘要與閉環流程

本任務依五階段 closed-loop control 執行:QA Subagent 以「獨立重算 oracle(與 app 零共用程式碼)+ Playwright E2E + scenario injection」三視角稽核持倉成本、損益、現金流對帳、跨幣別與 XIRR 五大領域;Master 對每一筆 finding 做獨立 sanity check 後產出 Remediation Blueprint;Repair Subagents 按模組分組執行修復;回歸驗證(Master probes + 全套 pytest + QA R2 局部回歸)後宣告收斂。

STAGE 1QA E2E 稽核3 組資料集、5 領域、372+ 核對點
STAGE 2Master 覆核與藍圖逐項驗證,更正 1 筆誤判
STAGE 3模組化修復3 個 Repair Subagents(A 跑 2 輪)
STAGE 4回歸與收斂Probes V1–V7 + 4,752 tests + QA R2
STAGE 5結案報告本文件 + 修復回寫本機專案

核心結論:五大金額計算領域未發現任何 P0/P1 錯誤 — 三組資料集(含 1,214 列真實 Schwab 對帳歷史與外部 ground truth)上,每一筆重算的 cost basis、realized/unrealized PnL、cash pool、FX pool、KPI rollup 與 XIRR 均與 API 輸出精確一致(Decimal-string 等值,fee engine 16/16 手冊 worked examples 全中,XIRR closed-form 探針 365 天 +10% 精確得 0.1000)。確認的 6 筆缺陷皆屬匯入流程防護、訊息衛生、顯示排序與文件同步範疇,已全數修復並回歸驗證。
