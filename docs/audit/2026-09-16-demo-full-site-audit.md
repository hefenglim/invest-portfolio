## 三、系統面驗證（這些都測了，而且是對的）

### 3.1 金額與成本計算 — 94 項恆等式全過

以 `/api/dashboard` 原始 Decimal 字串獨立重算，三輪複驗皆全過：

- `已實現 + 未實現 = 資產損益`；`含匯兌總損益 = 資產損益 + 本金匯率效果 + 交易與融資成本`
- `Σ 各帳戶市值 = Σ 各市場市值 = Σ 各幣別（報告幣）= Σ 產業配置 = 總市值`
- `Σ 產業權重 = 1`；`Σ 逐檔權重 = 1`
- 逐檔（14 檔 × 6 項）：`市值 = 股數 × 現價`、`未實現 = 市值 − 調整成本`、`資本利得 = 市值 − 原始成本`、`未實現 = 資本利得 + 股利沖減`、`調整成本 = 原始成本 − 股利沖減`、`未實現% = 未實現 ÷ |原始成本|`
- **FX 三角一致性 < 0.001%**（修復前 0.0690%，修復後 0.000001%）

> **「未實現損益%」以原始成本為分母（分子含股利）** 是 `portfolio/dashboard.py:688-698` 記載的刻意決定（調整成本可能 ≤ 0 會翻轉正負號，放空部位亦然），抽屜內明確標示「vs 原始成本」。**判定為正確，非缺陷。**
