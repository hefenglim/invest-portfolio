四處根因分歧 —— 前後機制演示

稽核報告推測的根因，有四處在實作時被證實是錯的。這份文件讓你親手驗證： 前三個是真實的 CSS 級聯問題，放在頁內的 iframe 沙盒裡跑真實的瀏覽器級聯 ——不是截圖、不是模擬——你可以切換「原報告建議 / 實際修法」，看 computed style 當場改變。 第四個是領域規則，附可輸入的雙規則對照器。

①topbar：同特異性下「後面的贏」

原報告推測

flex 子項的 min-width 解析為 auto，所以拒絕收縮。 建議：加 min-width: 0。

實測根因

檔案後段另有一條 .topbar { flex-wrap: nowrap }。 與基礎規則同特異性，靠出現順序勝出。 不論加不加 min-width: 0，都不會換行。

/* styles.css 第 253 行附近 —— 基礎規則 */
.topbar { display:flex; align-items:center; gap:14px; flex-wrap: wrap; }
.topbar > * { min-width: 0; }              ← 原報告建議加的這行

/* …中間隔了 1,400 行… styles.css 第 1714 行「標籤防折行」段 */
.topbar { flex-wrap: nowrap; }            ← 同特異性 (0,1,0)，但在後面 → 它贏

實驗：切換三種狀態，看 getComputedStyle(topbar).flex-wrap

②KPI 帶：媒體查詢不增加特異性

原報告推測

與 topbar 同一個原因，flex／grid 壓縮所致。

實測根因

.kpi-band.v2 是兩個 class（0,2,0）， @media { .kpi-band } 只有一個（0,1,0）—— 媒體查詢本身不貢獻特異性。所以那個斷點對 v2 帶完全失效， 761–1280px 一路維持 5 欄。

選擇器特異性在斷點內誰勝出
.kpi-band.v2（第 1095 行）(0,2,0) 勝出 → 維持 5 個固定欄
@media (max-width:1280px) { .kpi-band }(0,1,0) 被壓過 → 這個斷點形同不存在
@media (max-width:760px) { .kpi-band, .kpi-band.v2 }(0,2,0) 有寫 v2 → 行動版一直是好的（所以只有中間寬度壞掉）

③資料中心：nowrap 套到正文段落，而 inline 的 overflow 是無效的

原報告推測

表格缺少水平捲動容器。

實測根因

表格本來就有正確的容器。撐破頁面的是全域 .panel-sub { white-space: nowrap } 套到了正文段落； 而該 <span> 是 inline， overflow: hidden 對非替換 inline 元素無效， 連省略號都沒生效，於是變成一條 584px 不可折行的長線。

/* 這條規則是為「面板標題列」寫的，那裡它是 flex 項目，裁一行是預期行為 */
.panel-sub { white-space: nowrap; overflow: hidden; text-overflow: ellipsis; }

/* 但同一個 class 也用在正文： */
<div class="set-body"><span class="panel-sub">本頁為唯讀統計。未來將於此設定…</span></div>
   ↑ inline span → overflow:hidden 無效 → 不裁、不換行 → 直接把容器撐開

④股利檢核：那條等式只是美股 DRIP 的，不是通則

原報告建議

gross − withholding == net，不符即拒絕。

實測問題

台股二代健保補充保費與匯費、美股 ADR fee 都會讓 net < gross 而不屬於 withholding。這條規則會拒絕真實資料， 逼使用者去竄改 gross。實際採用守恆式： 預扣 + 淨額 ≤ 總額——一筆配息不可能「發出」比宣告更多的錢。

⑤一句話總結與防重演

案例照原建議實作的後果
① topbar完全無效——後段那條 nowrap 仍然勝出

④ 股利檢核產生迴歸——誤殺二代健保／ADR fee 的合法資料

防重演的做法已經落地：

  • 稽核報告改標信心度：每條發現拆成 症狀（量測） 與 根因（已驗證／推測待驗）， 你在核准前就知道哪幾項可能變形。
  • LESSONS_LEARNED.md 已寫入一條「類別」教訓（不是四條個案）： 靜態閱讀在 CSS 級聯 與 領域規則現實 兩處系統性不可靠； 改 CSS 前後都要讀 computed value；收緊領域不變量前要從市場規則列舉合法例外。
  • 出貨時寫進 CHANGELOG：一小節「修法與稽核推測不同之處」， 因為你每次發版都會看 CHANGELOG，不會再回頭讀一次性的報告。
  • 程式碼現場註解（已完成）：例如被移除的那條 nowrap 原位置留了 「Do NOT re-add a nowrap here」。
